# Сапёр

Три уровня сложности и своё поле, флажки, быстрые открытия по цифре, рекорды и режим «без угадывания», где поле всегда решается логикой.

## Установка

Приложение семейства **Winter Hub** (Android + Windows). Удобнее всего ставить и обновлять через Winter Hub, либо скачать файл из раздела **Releases**: `Winter-Mines.apk` для телефона, `Winter-Mines-Setup.exe` для ПК.

## Как устроено

Flutter (Dart). lib/game.dart — логика поля, lib/main.dart — экраны.

Сборку делает GitHub Actions при каждом изменении в `main`: анализ кода, тесты (`test/`), сборка APK и установщика для Windows, подпись постоянным ключом (общие скрипты в `winter-hub/ci`) и публикация в Releases.
